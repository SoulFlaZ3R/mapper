# Security policy

## Supported versions

Only the latest release on the [Releases page](https://github.com/SoulFlaZ3R/mapper/releases) receives fixes.

## Reporting a vulnerability

Please report security problems privately: on GitHub open **Security → Report a vulnerability** in this
repository. If that button is not available, open an issue that only says you found a security problem,
without details, and you will be contacted.

Include the Mapper version (Settings → About), the Windows version, the steps to reproduce and what
happens. You will get an answer as soon as possible; fixes are released as a new version with a note
in the [CHANGELOG](CHANGELOG.md).

What the app protects against, how each protection is tested, what it stores on your computer and
